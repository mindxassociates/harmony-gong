# Harmony Gong — Bilingual Psychotherapy Landing Page

Static bilingual one-page website for Harmony Gong, LMHC-D, LPC.

## Files
- `index.html` — English
- `zh.html` — Simplified Chinese
- `style.css` — responsive mellow-green design system
- `main.js` — navigation, reveal, and scroll interactions
- `assets/harmony-gong-profile-hd.jpg` — high-resolution optimized portrait

The pages include insurance/EAP information, direct contact information, and separate embedded Zcal scheduling widgets for English and Chinese visitors.

Designed for static hosting such as GitHub Pages. No build step is required.
